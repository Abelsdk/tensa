# data/

Datasets are **not** committed. This folder holds download/generation scripts and their output stays local (gitignored).

| Dataset | Used for | How to get it |
|---|---|---|
| Simulated cohort | Timeline | generated by `ml/timeline/simulator.py` (clearly labelled simulated) |
| BEIR biomedical | Retrieval | `pip install beir` or Hugging Face |
| PubMed Central OA | Ask corpus | NCBI OA subset |
| MedQuAD | Generator / Router | github.com/abachaa/MedQuAD |
| MRNet | Scan | free registration with Stanford AIMI |
